# Милый сайт-подарок для Сони

Открой `index.html` в браузере. Сайт работает без сервера и зависимостей.

Фотографии лежат в папке `img`. Подписи, вопросы теста и комплименты можно менять в `script.js`.

## Render

Для Static Site на Render:

- Build Command: `true` или пусто
- Publish Directory: `./`

Если оставить Publish Directory как `build`, деплой упадет, потому что в этом проекте нет отдельной папки сборки.
